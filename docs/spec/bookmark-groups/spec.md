# 组合收藏（勾选标签页 · 留下组合备注 · 首页筛选 · 一键重新打开）

让用户把一起研究的多个网页保存为一个有名称、有备注的收藏组合，安心关闭选中的标签页，下次从拾绪首页一次重新打开。例如，用户同时打开几篇华为小艺接入文档和一些购物、视频页面，可以只选中相关文档，保存为「小艺接入」，留下「下次从账号配置开始」的备注，再关闭这些文档。

收藏面板提供「单页收藏／组合收藏」两种模式。单页收藏继续保存一个网页及其收藏理由、四维分类；组合收藏保存组合名称、组合备注及用户明确选择的页面顺序。一个网页在当前收藏库中只有一份收藏，可以出现在多个组合中；组合备注属于整组，页面自己的收藏理由与分类分别保留。组合由用户添加、移除页面来维护，动态视图继续按筛选规则展示结果。

本次范围覆盖 Chrome 和 Firefox 的收藏面板、首页组合入口与筛选、组合编辑、批量打开，以及已有账号版中的同步和存档。默认只列出唤起面板所在窗口的标签页，只预选当前可收藏页面；其他页面由用户勾选。无账号版本和未登录状态支持完整的本地组合收藏与找回。页面重新打开以保存的网址和顺序为准；网页登录状态、页面滚动位置、表单草稿与网页内容本身由网站和浏览器管理。

与现有需求的衔接：《收藏当前页面》保留为单页模式的行为依据，本 spec 增加组合模式及其独立草稿、长列表与键盘行为；《插件主页》采用 2026-09-14 修订后的「全部收藏」默认入口，并在其中增加单页／组合切换和所属组合筛选；《同步状态与快照存档》增加组合的同步、计数与恢复内容。相关原文分别位于 `docs/spec/capture/spec.md`、`docs/spec/homepage/spec.md`、`docs/spec/sync-archive/spec.md`。本 spec 描述新增功能的验收目标。

## feat01: 在收藏面板切换单页与组合收藏

用户通过面板内的模式切换入口，选择收藏当前一个页面，或组合收藏一组选中的页面。

场景1: 默认打开单页收藏

- GIVEN 用户正在浏览一个普通网页
- WHEN 用户点击扩展图标或使用现有收藏快捷键
- THEN 面板默认显示「单页收藏」，沿用当前页面信息、收藏理由、四维分类和保存操作；同时提供「组合收藏」切换入口

场景2: 切换到组合收藏

- GIVEN 用户已打开收藏面板
- WHEN 用户点击「组合收藏」
- THEN 面板显示组合名称、组合备注、当前窗口的标签页列表、选择数量以及组合保存按钮；组合模式中的分类展示以各页面原有分类为准，本次填写集中于组合名称和备注

场景3: 同一次打开内切换保留各自草稿

- GIVEN 用户在单页模式填写了理由和分类，又在组合模式选择了页面并填写组合备注
- WHEN 用户来回切换两种模式
- THEN 两种模式分别恢复各自输入和选择；保存操作只提交当前模式的草稿，单页模式填写的分类和理由只属于该单页草稿

场景4: 关闭后重新打开

- GIVEN 用户尚未点击保存，面板中有组合草稿
- WHEN 用户按 Esc、关闭面板或通过面板入口前往首页，然后重新打开面板
- THEN 面板回到「单页收藏」初始状态；上一次的组合草稿按放弃处理，收藏库保持上一次成功保存后的内容

场景5: 当前页面无法收藏时组合入口仍可使用

- GIVEN 当前页面是浏览器内部页面、本地文件页或扩展页面，同一窗口还有普通网页
- WHEN 用户打开收藏面板并切换到「组合收藏」
- THEN 用户可从列表选择其他普通网页；当前页面显示「此页面无法收藏」并处于不可选状态

场景6: 页面列表读取失败

- GIVEN 用户已进入组合模式
- WHEN 打开的页面列表读取失败
- THEN 显示「读取打开的页面失败，请重试」和重试入口，组合保存按钮暂时不可用；已输入的名称与备注保留，用户仍可切回单页模式

## feat02: 明确选择组合中的页面

用户从当前窗口中按标题、网址查找并勾选相关页面，随时核对选择范围。

场景1: 初次展示与默认选择

- GIVEN 当前窗口有三篇华为文档、一个购物页和一个视频页，当前正在查看其中一篇华为文档
- WHEN 用户本次首次进入组合模式
- THEN 列表按浏览器标签页顺序展示标题和网址，并标明当前页、固定页及已收藏的页面；仅当前华为文档默认选中，购物页和视频页等待用户自行选择

场景2: 当前窗口范围

- GIVEN 用户打开了两个浏览器窗口，并从第一个窗口唤起收藏面板
- WHEN 用户查看组合模式的页面列表
- THEN 列表只包含第一个窗口的标签页；通过快捷键唤起的独立收藏面板也使用原网页所在窗口的列表

场景3: 按标题或网址筛选并批量勾选

- GIVEN 页面列表较长
- WHEN 用户输入关键词筛选标题或网址，并点击「全选当前结果」或逐项勾选
- THEN 本次操作只选择当前结果中可收藏的页面；其他已选页面继续保留，界面持续显示全部已选数量及被筛选隐藏的已选数量，提供「仅看已选」入口

场景4: 取消选择与空选择

- GIVEN 用户已经选中若干页面
- WHEN 用户取消某页选择，或点击「清空已选」
- THEN 选中数量立即更新；选中数量为零时显示「请选择至少一个页面」，组合保存按钮不可用；一个页面也可以保存为组合

场景5: 页面过多时核对范围

- GIVEN 当前窗口页面数量超出面板可展示高度
- WHEN 用户浏览和勾选列表
- THEN 标签页列表可滚动，模式入口、已选数量及保存操作持续可见；长标题和长网址可以截断展示，并提供查看完整内容的方式

场景6: 普通页面与不可收藏页面混合

- GIVEN 当前窗口包含普通网页、浏览器内部页、本地文件页及扩展页面
- WHEN 用户查看列表或全选当前结果
- THEN 普通网页可选；其余页面显示不可收藏说明，全选只作用于可收藏页面

场景7: 打开列表后新增或重排标签页

- GIVEN 用户已经勾选页面，又从浏览器新增或调整了一些标签页
- WHEN 用户点击「刷新页面列表」
- THEN 列表更新为当前窗口的页面与顺序，仍然存在且地址相同的页面保留选择，新出现的页面等待勾选；已经输入的名称和备注保留

场景8: 已选页面被关闭或跳转

- GIVEN 用户勾选页面后，该标签页在保存前被关闭或跳转到另一个地址
- WHEN 用户刷新列表或点击保存
- THEN 面板指出发生变化的条目并暂停本次保存；用户可以明确选择保留原先看到的网址、改选当前页面或移除该项，确认后的页面清单成为保存范围

场景9: 存在同一页面的多个标签页

- GIVEN 用户选中的三个标签页中，有两个指向同一页面，区别仅为已有判重规则忽略的跟踪信息
- WHEN 用户查看保存前的选择汇总
- THEN 显示「已选 3 个标签页，保存为 2 个页面」；组合中的页面顺序按每个页面首次出现在已选列表中的位置确定，关闭数量按选中的实际标签页计算

## feat03: 给组合命名并留下一段话

用户通过一个可修改的名称和一段可选备注，为下一次找回这组页面留下线索。

场景1: 自动预填组合名称

- GIVEN 用户进入新建组合模式并首次得到可保存的选择
- WHEN 用户查看名称输入框
- THEN 名称预填为首个已选页面的标题，标题为空时使用其网址；用户可以直接保存，也可以修改为「小艺接入」等名称

场景2: 填写组合备注

- GIVEN 用户选中了小艺接入相关文档
- WHEN 用户填写「下次从账号配置开始，重点看设备端接入要求」
- THEN 该文字作为组合备注显示和保存，供首页搜索、组合卡片与详情展示；每个页面原有的收藏理由继续分别保留

场景3: 空名称与空备注

- GIVEN 用户清空名称，备注也留空
- WHEN 用户点击保存
- THEN 名称使用保存时首个已选页面的标题或网址，备注按空内容保存，组合正常建立

场景4: 多行输入和特殊字符

- GIVEN 用户正在编辑组合名称或备注
- WHEN 用户输入中文、符号或长文字，或在备注内按 Enter
- THEN 名称支持普通文字与符号，备注支持换行；备注中的 Enter 用于换行，组合保存由明确点击保存按钮触发；输入法确认候选文字时正常上屏

场景5: 同名组合

- GIVEN 当前库已经存在一个名为「小艺接入」的组合
- WHEN 用户在新建组合时使用相同名称
- THEN 面板提示「已有同名组合」，并提供「加入已有组合」与「仍然新建」选择；用户明确选择后继续，列表使用备注、页面数和创建时间帮助区分同名组合

场景6: 保存失败后继续编辑

- GIVEN 用户已经填写组合名称和备注
- WHEN 本次保存失败
- THEN 面板保留名称、备注和已选页面，显示失败原因与重试入口，用户可以继续修改后再保存

## feat04: 保存组合并按选择关闭标签页

用户可以只保存组合，也可以在组合完整保存成功后关闭本次选择的标签页。

场景1: 仅保存新组合

- GIVEN 用户已选中三个不同页面并填写组合信息
- WHEN 用户点击「保存这 3 个页面」
- THEN 当前收藏库出现一个包含这三个页面的组合，保留选择时的页面顺序和组合备注；页面同时可在单页收藏中找到，浏览器标签页继续保留

场景2: 保存并关闭选中标签页

- GIVEN 用户已经确认组合信息和页面选择
- WHEN 用户点击「保存并关闭这 N 个标签页」
- THEN 所选页面和组合信息完整保存成功后，关闭本次选中且仍对应所保存页面的普通标签页；其他标签页继续保留，首页可以找到组合并一键打开

场景3: 组合引用已收藏页面

- GIVEN 所选页面中，一页已有收藏理由、分类和收藏时间，另外两页尚未收藏
- WHEN 用户保存组合
- THEN 已收藏页面使用原有收藏，保留原有标题、理由、分类和收藏时间；另两页新增为单页收藏，理由为空、主题与形态及用途为空、状态为 Inbox；组合备注只保存在组合上

场景4: 页面曾经被删除

- GIVEN 所选页面曾从当前收藏库删除
- WHEN 用户明确选择该页面并保存组合
- THEN 页面重新进入收藏库并加入本次组合，收藏时间按本次重新收藏记录，状态默认 Inbox；旧组合中的成员关系按先前删除后的状态保留，本次加入的组合以用户本次选择为准

场景5: 本地保存失败

- GIVEN 组合信息或所选页面在本机保存时发生错误
- WHEN 本次保存结束
- THEN 显示「组合保存失败，请重试」，本次选择的标签页全部保留，收藏库保持本次操作前的内容；名称、备注和选择继续留在草稿中；用户重试成功后只得到本次目标组合和去重后的页面

场景6: 保存过程中的重复点击与面板关闭

- GIVEN 用户已经发起组合保存
- WHEN 用户重复点击保存按钮，或者随后关闭面板、切换到别的标签页
- THEN 重复点击只对应本次操作，已经发起的保存继续完成；用户稍后打开首页可以查看成功保存的组合及本次操作结果

场景7: 固定标签页与已经关闭的标签页

- GIVEN 保存范围中包含固定标签页，以及用户明确保留原网址但实际已经关闭的页面
- WHEN 组合保存成功并执行关闭
- THEN 固定标签页继续保持打开，已经关闭的页面按已结束处理；结果分别说明已保存页面数、实际关闭数、固定保留数和此前已关闭数

场景8: 保存后页面跳转或关闭失败

- GIVEN 组合已保存成功，某个已选标签页此时已经跳转到其他网址，或浏览器拒绝关闭某个标签页
- WHEN 执行关闭操作
- THEN 地址已变化的标签页予以保留，其他符合条件的已选标签页继续关闭；显示「组合已保存」以及保留或关闭失败的具体条目，用户可从首页组合详情查看本机这次操作结果

场景9: 关闭窗口的最后一组页面

- GIVEN 本次选择覆盖了窗口内所有可关闭的标签页
- WHEN 组合完整保存成功并关闭这些标签页
- THEN 该窗口可以随最后一个标签页关闭；用户再次打开浏览器和拾绪时，仍能从首页找到已保存组合

场景10: 本地成功而账号同步失败

- GIVEN 用户已登录，本机保存成功，服务器此时无法连接
- WHEN 用户执行保存并关闭
- THEN 本地组合可正常找回，关闭操作照常按本次选择执行；界面显示组合「待同步」，稍后按已有同步方式补传

## feat05: 在首页浏览单页收藏和组合收藏

用户在首页「全部收藏」中切换单页列表与组合列表，快速找到之前保存的一组页面。

场景1: 默认入口与模式切换

- GIVEN 用户打开拾绪首页
- WHEN 用户查看「全部收藏」
- THEN 内容区提供「单页收藏」「组合收藏」两个切换入口，首次默认展示单页收藏；用户点击「组合收藏」后显示组合卡片列表

场景2: 组合卡片的信息和顺序

- GIVEN 当前库存在多个组合
- WHEN 用户进入组合收藏列表
- THEN 全部组合按最近修改时间从新到旧展示；每张卡片显示名称、备注预览、可用页面数、最近修改时间和前几个页面的标题或来源，并提供「一键打开 N 页」和「查看组合」入口

场景3: 查看完整组合

- GIVEN 组合备注或页面列表在卡片上只显示预览
- WHEN 用户点击「查看组合」
- THEN 详情完整展示组合备注、创建与修改时间，以及按保存顺序排列的页面标题、网址、单页收藏理由和分类；每个页面都有单独打开入口

场景4: 直接进入、刷新和返回组合

- GIVEN 用户已经进入组合列表或某个组合详情
- WHEN 用户刷新页面、使用浏览器前进后退，或从收藏成功后的「查看组合」入口进入
- THEN 首页恢复对应的单页／组合模式或组合详情；返回列表时恢复同一次浏览中的搜索与筛选条件

场景5: 无组合与空组合

- GIVEN 当前库尚无组合，或某个组合的全部页面已被移除
- WHEN 用户查看组合列表或详情
- THEN 尚无组合时显示「还没有组合收藏，可以从收藏面板勾选打开的页面保存」；空组合保留名称和备注，显示「0 个页面」及添加入口，一键打开暂时不可用

场景6: 读取失败与组合已被删除

- GIVEN 用户正在进入组合列表或详情
- WHEN 读取失败，或目标组合已经从当前库删除
- THEN 读取失败时显示错误和重试入口；目标组合已删除时显示「这个组合已删除」及返回组合列表入口，两种情况分别说明

场景7: 收藏与组合分别计数

- GIVEN 当前库有 20 个不同网页和 3 个组合，其中一个网页同时属于两个组合
- WHEN 用户查看首页汇总及收藏面板顶栏
- THEN 分别显示「20 条收藏 · 3 个组合」；网页按独立收藏计数，组合按组合计数；筛选结果计数以当前显示的单页或组合为单位

场景8: 单页模式包含已经加入组合的收藏

- GIVEN 当前库有三条属于「小艺接入」组合的收藏和两条尚未加入组合的收藏
- WHEN 用户在单页收藏模式中使用「所属组合：全部」且清空其他条件
- THEN 展示全部五条收藏，每个网页只出现一次；用户可以通过组合入口一次打开三个成员，也可以从这里单独打开任一收藏

## feat06: 按组合筛选页面并搜索组合

用户既可以在单页列表筛出某个组合的成员，也可以直接用名称或备注找到整个组合。

场景1: 单页列表按所属组合筛选

- GIVEN 用户位于首页单页收藏列表
- WHEN 用户选择「所属组合」中的「小艺接入」
- THEN 列表只显示该组合内的可用收藏；「所属组合」默认值为「全部」，一次选择一个具体组合，已选组合名称持续可见且可以清除

场景2: 所属组合与现有条件共同筛选

- GIVEN 用户选择「小艺接入」组合，并选择形态「文档」、收藏时间「最近 7 天」及一个搜索关键词
- WHEN 筛选生效
- THEN 显示同时满足组合归属、四维条件、单页收藏时间和关键词的页面；四维候选计数也以组合归属、时间与搜索条件为前提计算，已选选项持续可见；登录版中的待同步筛选按同样方式叠加

场景3: 清除、无结果和组合选择器搜索

- GIVEN 当前库有较多组合，或所选组合与其他条件组合后没有匹配页面
- WHEN 用户输入部分组合名称查找选项，或清除当前条件

## feat07: 一键重新打开组合页面

用户可以恢复整个组合，也可以从组合详情只打开本次需要的页面。

场景1: 一键打开完整组合

- GIVEN 用户找到含六个可用页面的组合
- WHEN 用户点击「一键打开 6 页」
- THEN 浏览器在一个新窗口中按组合顺序打开这六个页面，首个页面处于当前显示状态；原窗口继续保留，组合内容和最近修改时间保持原值

场景2: 单独打开或勾选部分页面

- GIVEN 用户正在查看组合详情
- WHEN 用户点击一个页面的打开入口，或勾选其中三个页面后点击「打开所选 3 页」
- THEN 单页在当前浏览器窗口的新标签页打开；多个所选页面在同一个新窗口中按组合顺序打开；本次选择用于打开范围，组合成员继续按原清单保存

场景3: 浏览器里已经打开过其中某页

- GIVEN 组合中的一个页面已在其他窗口打开
- WHEN 用户一键打开组合
- THEN 新窗口完整打开本次组合，原先打开的页面保留在原位置；同一组合清单中的重复页面按照保存时去重后的清单只打开一次

场景4: 打开过程中的重复点击

- GIVEN 本次批量打开正在进行
- WHEN 用户重复点击该次打开按钮
- THEN 当前操作显示进行中并继续完成，重复点击归于当前这次操作；完成后用户可以再次明确发起一次新的打开

场景5: 创建窗口或部分页面打开失败

- GIVEN 用户发起批量打开
- WHEN 新窗口创建失败，或部分标签页创建失败
- THEN 显示实际成功打开的数量以及失败页面；成功的页面继续保留，提供仅重试失败页面的入口，新窗口创建失败时提供重试整个操作的入口

场景6: 页面失效、需要登录或设备离线

- GIVEN 浏览器能够打开所保存的网址，但网站已失效、要求登录，或设备当前离线
- WHEN 用户打开组合
- THEN 浏览器显示对应网站的实际访问结果，组合及备注仍可在拾绪中查看；批量打开结果只说明已打开的标签页数量

场景7: 组合为空或存在暂时不可用的页面

- GIVEN 组合为空，或跨设备获取过程中有些成员页面暂时无法读取
- WHEN 用户查看打开入口
- THEN 入口显示当前可用页面数量，暂时不可用的成员单独说明；没有可用页面时打开按钮不可用，有可用页面时用户可以明确打开可用部分

## feat08: 维护组合名称、备注和成员

用户可以继续补充资料、调整顺序及移除页面，也可以删除整个组合入口。

场景1: 修改名称与备注

- GIVEN 用户正在查看一个已有组合
- WHEN 用户编辑名称或备注并保存
- THEN 组合卡片、详情与搜索使用最新内容，最近修改时间更新；名称清空时提示「请输入组合名称」，备注可以清空；取消编辑则恢复上一次保存的内容

场景2: 从打开的页面追加到已有组合

- GIVEN 用户正在收藏一个新页面，或在组合模式中选中了多个页面
- WHEN 用户在组合模式选择「加入已有组合」，按部分名称搜索并选中「小艺接入」，然后保存
- THEN 新页面按本次选择顺序追加到组合末尾，组合已有成员继续保留原顺序；已经在组内的页面显示「已在组合中」并沿用原成员；一个页面也可用此入口加入已有组合

场景3: 追加时保留组合与单页的已有文字

- GIVEN 用户已经填写新建组合草稿，随后切换到加入已有组合
- WHEN 用户选中已有组合并保存追加页面
- THEN 面板展示已有组合名称和备注供核对，本次只追加页面；新建草稿单独保留在新建模式，组合文字的修改通过组合详情的编辑入口完成，各单页理由与分类继续保留

场景4: 从收藏库补充已有页面与调整顺序

- GIVEN 用户位于组合详情，当前库还有其他收藏
- WHEN 用户点击「添加已有收藏」，按标题、来源域名或单页收藏理由搜索后勾选，并保存；或使用页面行的上移／下移操作调整顺序
- THEN 新选中的页面加入组合，重复成员沿用原位置；保存后的页面顺序用于后续批量打开，同一网页也可以加入其他组合

场景5: 从组合移除页面与移除最后一页

- GIVEN 组合包含若干页面
- WHEN 用户移除某个成员，或移除最后一个成员并保存
- THEN 组合成员数和预览更新，被移除的页面仍在单页收藏及其他所属组合中；移除最后一页后组合保留名称和备注，显示「0 个页面」并允许继续添加

场景6: 删除整个组合

- GIVEN 用户已找到一个组合
- WHEN 用户点击「删除组合」，在确认提示中确认「删除这个组合入口，保留其中的单页收藏」
- THEN 组合从列表和所属组合选项中移除，所有单页收藏及其他组合继续保留；取消确认则保留该组合

场景7: 收藏库中的页面被删除

- GIVEN 某页属于两个组合
- WHEN 该页从收藏库删除，或该删除随同步带到当前设备
- THEN 该页从两个组合的可用成员中移除，成员数量与打开范围相应更新；组合说明有成员被删除，其他页面与组合备注保留；以后重新收藏该页时，加入组合由用户重新选择

场景8: 修改失败或编辑过程中组合变化

- GIVEN 用户有尚未保存的组合修改
- WHEN 保存失败，或保存前组合已在别处被更新或删除
- THEN 保存失败时保留当前草稿并提供重试；发现组合已更新时提示重新载入最新内容并保留本次草稿供参考；组合已删除时提示原组合已删除，并提供返回列表或按本次草稿另存新组合的入口

## feat09: 在当前收藏库使用和同步组合

组合与页面一起归属于当前收藏库，账号版可以把完整组合带到其他设备，日常保存和找回优先使用本机内容。

场景1: 未登录与无账号版本

- GIVEN 用户未登录，或使用无账号版本
- WHEN 用户保存、筛选、编辑或重新打开组合
- THEN 这些功能全部可用，内容保存在默认收藏库，界面展示本地收藏与组合数量

场景2: 登录、登出和切换账号

- GIVEN 默认库、账号 A 和账号 B 各有自己的组合
- WHEN 用户登录、登出或切换账号
- THEN 首页、组合选择器与详情显示当前库的内容；原库的组合与尚待同步的修改保留在原库，切回后可继续使用；首次切换与离线切换条件沿用现有账号行为

场景3: 填写或保存期间切换收藏库

- GIVEN 用户在库 A 打开组合草稿，随后收藏库切换为 B
- WHEN 用户尚未发起保存，或保存已经开始
- THEN 尚未保存时提示「收藏库已切换，请重新选择保存内容」并重置为 B 的可选内容；已经开始的保存明确归入发起时的库 A，完成提示标明所属库，关闭操作继续以这次已成功保存的页面为范围

场景4: 手动同步与自动同步

- GIVEN 用户已登录，并新建或修改了组合
- WHEN 用户手动同步收藏，或已有自动同步开关触发同步
- THEN 组合名称、备注、成员和顺序，以及其中新增的页面一起同步；同一账号的另一台设备同步完成后，可以完整查看并重新打开这组页面

场景5: 同步状态与分别汇总

- GIVEN 账号库有待同步的组合或成员页面
- WHEN 用户查看首页、组合卡片、待同步组合筛选或服务器概览
- THEN 页面和组合数量分别统计；组合自身修改和成员页面都已成功同步时才显示组合「已同步」，其余情况显示「待同步」；待同步组合筛选能找到这些组合，服务器概览分别显示最近成功取得的收藏与组合数量

场景6: 同步失败或服务器尚未支持组合

- GIVEN 本地组合保存成功，但服务器连接失败，或当前服务器暂时无法保存组合
- WHEN 用户同步
- THEN 本地组合及成员完整保留、可查看与打开，组合继续显示待同步；提示连接失败或「当前服务器暂不支持组合同步」及相应处理建议，页面同步和组合同步的实际结果分别说明

场景7: 其他设备修改或删除组合

- GIVEN 同一账号在其他设备修改或删除了某个组合
- WHEN 当前设备同步完成
- THEN 当前组合列表、名称、备注和打开范围反映同步后的内容；删除组合只移除组合入口，成员页面按各自的收藏状态继续保留

场景8: 两台设备同时修改

- GIVEN 两台设备离线修改同一个组合的名称、备注或成员顺序
- WHEN 两台设备重新完成同步
- THEN 该组合采用最后修改的一份完整内容，各设备最终展示相同的名称、备注和成员顺序；本地修改期间遇到其他更新时，编辑提示沿用 feat08 场景8

场景9: 组合先到达而部分页面尚未到达

- GIVEN 当前设备已经取得组合信息，部分成员页面尚未取得
- WHEN 用户查看组合
- THEN 显示已取得的页面与「部分页面待同步」说明，组合继续显示待同步；后续同步取得页面后，完整列表和打开数量自动更新；已经确认删除的成员按 feat08 场景7 处理

场景10: 离线切回仅保留空组合的账号库

- GIVEN 本机曾使用账号 A，A 的页面已经全部移除，但仍有保留名称和备注的空组合
- WHEN 用户在离线状态切回本机保存的账号 A
- THEN A 的空组合及备注仍可查看和编辑，按本机已有收藏库的切换规则处理
