# 拾绪（x-threadpick）隐私政策

**更新日期：2026-09-13 · 适用版本：0.1.0 及以后（本地版）**

拾绪是一款本地书签收藏与管理扩展。本政策描述它处理哪些信息、存在哪里。

## 核心承诺：我们不收集任何数据

- 拾绪**没有网络权限**：扩展清单中不含任何主机（host）权限，技术上无法向任何网站或服务器发送你的数据。
- 你的所有数据——收藏的网址、标题、一句话理由、分类属性、分类维度取值、设置——**只保存在你自己的浏览器本地**（IndexedDB）。
- 不上传、不同步、无遥测、无统计分析、无广告、无第三方 SDK。
- 卸载扩展或清除浏览器站点数据即永久删除全部数据；我们没有任何副本。

## 权限用途说明

| 权限                     | 用途                                                                                                                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bookmarks`              | 读取浏览器书签树，供你在「导入」页搜索并勾选导入到拾绪                                                                                                                                 |
| `storage`                | 在浏览器本地保存你的收藏与设置                                                                                                                                                         |
| `activeTab`              | 你主动唤起收藏面板（快捷键或点击图标）时，读取当前页面的网址与标题用于收藏                                                                                                             |
| `tabs` / `webNavigation` | 仅用于可选功能「新标签页接管」（默认关闭）：识别你手动新建的空白标签页并将其替换为拾绪主页。此权限组合会触发浏览器「读取您的浏览记录」安装警告，但拾绪不会记录、存储或上传你的浏览历史 |

## 关于「账号同步」功能

当前商店版本为**纯本地版，不含账号与同步功能**。若未来版本引入可选的账号同步，届时将更新本政策、明示传输哪些数据，并在你主动登录前不发生任何网络传输。

## 未满 13 岁

拾绪不面向 13 岁以下儿童，也不有意收集任何用户的个人信息。
