- **Distribution**：建议先 unlisted 内测，稳定后切 public
- **Remote code**：No（React 等全部打包进产物，无远程加载）
- **Single purpose**：本地书签的收藏、分类与检索（保存网页、多维归类、浏览与导入已有书签）

### 权限理由（逐条粘贴到 Permission justification）

- `bookmarks`：读取浏览器书签树，供用户在导入页搜索、勾选并导入已有书签到本地收藏库。
- `storage`：在本地保存用户的收藏数据（网址、标题、理由、分类）与设置。
- `activeTab`：用户通过快捷键或工具栏图标主动唤起收藏面板时，读取当前活动标签页的网址与标题完成收藏。
- `tabs`、`webNavigation`：仅用于默认关闭的可选功能「新标签页接管」——识别手动新建的空白标签页并替换为扩展主页（含预渲染新标签页的兜底识别）。不记录、不上传任何浏览历史。
- **Host permissions**：本扩展不申请任何 host 权限，无任何跨站网络请求。

### Data usage 披露（开发者后台表单）

- 「Does your item collect or use any user data?」→ **No**。
  依据：所有数据仅存浏览器本地 IndexedDB，扩展无 host 权限、无任何网络请求，数据不离开设备（对应用户手册中的隐私政策页）。

## 详细描述（两店通用底稿）

> 拾绪（x-threadpick）是一个本地书签收藏与管理扩展：不是把网页丢进文件夹，而是记住「你为什么收藏它」。
>
> ✦ 核心特性
>
> - **保存并关闭 Tab**：Cmd/Ctrl+Shift+S 唤起面板，一句话理由可选输入，一键保存并关闭页面——敢收藏，就敢关掉。
> - **四维分类**：主题 / 形态 / 用途 / 状态，四个维度独立筛选；取值完全自定义，同一份收藏不用复制到多个文件夹。
> - **一句话理由**：「为什么收藏」单独成字段，参与检索——比标题和 URL 更接近你当时的记忆。
> - **零强制输入**：新收藏默认进 Inbox 状态，属性随时后补。
> - **导入已有书签**：整棵书签树展平成可搜索列表，勾选即导入，URL 自动规范化去重。
> - **可选的新标签页接管**：默认关闭，勾选后新建标签页打开拾绪主页。
>
> ✦ 隐私
>
> - 纯本地存储：所有数据只保存在你的浏览器里，扩展没有任何网络权限，不上传任何数据，无需注册账号。
> - 卸载即删除全部数据。
>
> ✦ 快捷键
>
> - Cmd/Ctrl+Shift+S：收藏当前页面
